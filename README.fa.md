# Bloom — Social Studio

این پروژه یک استودیوی تولید محتوای شبکه‌های اجتماعی برای گل‌فروشی Bloom است. کاربر یک عکس دسته‌گل، مناسبت و پیشنهاد فروش را انتخاب می‌کند و متن اختصاصی برای Instagram، Xiaohongshu (RedNote) و Facebook می‌گیرد؛ سپس پست‌ها را با Drag & Drop در تقویم هفتگی قرار می‌دهد.

برای اجرای پروژه:

```bash
pnpm install
pnpm dev:static
```

سپس آدرس `http://localhost:3000` را باز کنید.

مستندات کامل انگلیسی در [README.md](README.md)، راهنمای دمو در [docs/demo.md](docs/demo.md) و توضیحات معماری در [docs/architecture.md](docs/architecture.md) قرار دارد.
